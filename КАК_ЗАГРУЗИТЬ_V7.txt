КАК ЗАГРУЗИТЬ
1. Распакуйте SNACHALA_BOLNO_V7_FULL.zip.
2. В GitHub откройте репозиторий snachala-bolno.
3. Code → Add file → Upload files.
4. Перетащите ВСЁ содержимое распакованной папки в корень репозитория.
5. Нажмите Commit changes.
6. Подождите 2–5 минут.
7. Откройте https://snachala-bolno.ru/ и обновите Cmd+Shift+R.
